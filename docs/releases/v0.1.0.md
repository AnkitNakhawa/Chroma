# Chroma 0.1.0

The first Chroma developer release: a CPU-based, headless video composition engine
with a CLI, C ABI v1, and a Python wrapper.

## Start here

Follow the [installation and first-video quickstart](https://github.com/AnkitNakhawa/Chroma/blob/v0.1.0/docs/quickstart.md).
Each binary archive includes a three-second 720p animated example, the CLI,
shared C library and header, CMake config, Python wheel, documentation, and
private media tools. Keep the extracted directory together. No separate FFmpeg,
Homebrew, or compiler installation is needed for the CLI.

| Archive platform | Supported system |
| --- | --- |
| linux-x86_64 | glibc 2.35+, tested on Ubuntu 22.04 and 24.04 |
| darwin-arm64 | Apple Silicon, macOS 14+ |
| darwin-x86_64 | Intel, macOS 14+ |

Download the matching binary `.tar.gz` and `.sha256`. Each checksum file lists
both the binary archive and its optional `-sources.tar.gz`; the quickstart
shows how to verify just the binary download. Corresponding-source archives
include Chroma and the pinned bundled dependency sources and build recipe.

## Included

- JSON timelines with shapes, images, video, text shaping and layout, masks,
  blending, blur, color effects, and animated transforms and opacity.
- Audio trimming, gain, and mixing, with H.264/AAC MP4 output.
- Input preflight for assets, fonts, media compatibility, and timeline issues.
- Progress and cancellation through the CLI, C API, and Python, with existing
  output preservation on failure or cancellation.
- Bounded image/text caches and bounded-region text/shape rendering, guarded by
  pixel-equivalence and decoded video/audio quality checks.
- The offline-installable `chroma-render` wheel for Python 3.10+. It imports as
  `chroma_render` and needs the matching native archive; it is not on PyPI.

## Scope

This is a developer release, with CPU rendering and 8-bit SDR output. The bundled
OpenH264 encoder requires even MP4 dimensions of at least 16×16. Fonts and media
remain application-supplied assets. Preflight is an early compatibility check,
not a full media integrity scan. GPU execution, production HDR color management,
Windows packages, and Linux ARM packages are not included.

macOS SDK archives are ad-hoc signed, without Developer ID signing or
notarization; Gatekeeper may prevent downloaded binaries from running.

Chroma is Apache-2.0. Bundled dependencies retain their own licenses and notices,
including LGPL FFmpeg and BSD OpenH264; GPL and nonfree FFmpeg components are
disabled. See [packaging and license details](https://github.com/AnkitNakhawa/Chroma/blob/v0.1.0/packaging/README.md).
